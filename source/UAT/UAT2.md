# 用户验收测试优化建议 (UAT Phase 2)

## 客户管理

1. **备注展示**：新增的多行备注信息，在点击查看或编辑客户时，显示在详情页面，但新增时是多行输入的内容，被展示为单行显示，需要在客户详情页里的备注内容显示为输入时候的多行展示。

## 产品管理

1. **列表排序**：产品列表改成可以按表头字段点击排序，比如点击表头的"名称"，将依据产品名称进行升序或降序排序显示。

## 订单管理

1. **订单列表状态展示**：
	- 订单列表中的开票状态里的当前状态是”未开票”， 但未高亮显示。 只有在当前状态是“已开增值税专用发票”状态时是高亮显示。
	- 订单列表中的开票状态显示宽度太长，请将开票状态列表从当前的：未开票、已开增值税专用发票、已开普通发票、无需开票，修改为：未开票、已开专票、已开普票，删除“无需开票”状态。
	- 将操作列显示在第1列，订单编号列显示在最后一列。
   
2. **新建订单 — 产品选择**：
   - 产品名称的选择，点击选择产品后，列表中没有显示选中的产品名称，目前显示为空。 
   - 单价输入框和数量输入框前后取消+-两个按钮，具体单价和数量直接由客户输入，不需要+-号来修改。
   - 单价输入框和数量输入框的展示长度要能确保至少显示12位数据，目前输入框仅显示4位不足够。
	
3. **订单详情页状态展示与操作**：
   - 订单状态的操作，允许用户随时选中任何状态，而不是顺序更改状态。
   - 应允许多次部分收款，目前执行一次部分收款后，部分收款按钮不再显示，再也无法部分收款。
   - 对部分收款进行操作时，在本次收款金额的上方，应显示订单总金额，未收款金额。
   - "开票要求” 在“未开票"状态时，可以允许用户变更为其它选项。 
   
8. **附件上传问题**：目前上传 PNG 图片显示上传附件失败，报错信息：
   ```
	Failed to load resource: the server responded with a status of 400 (Bad Request)
   ```
