## 1. 系统简介

MyCRM 是一套轻量级的客户订单管理系统，帮助单人运营场景替代 Excel 手工记录，实现客户 — 产品 — 订单的全流程数字化管理。

**核心业务闭环：**

```
新建客户 → 新建产品 → 新建订单 → 变更状态 → 查看报表
```

**系统管理三种独立状态：**

| 状态类型 | 流转路径 |
|---------|---------|
| **订单状态** | 待处理 → 生产中 → 已发货 → 已完成 / 已取消 |
| **开票状态** | 未开票 → 已开增值税专用发票 / 已开普通发票 / 无需开票 |
| **收款状态** | 未收款 → 部分收款 → 已结清 |

## 2. 登录与退出

### 2.1 登录系统

1. 在浏览器中打开系统地址（例如 `http://localhost:3000`）
2. 输入管理员账号：
   - **邮箱：** `admin@no-crm.com`
   - **密码：** `admin123`
3. 点击 **"登录"** 按钮

> 首次登录后建议尽快修改密码。

### 2.2 退出系统

点击页面右上角的用户名称 → 选择 **"退出登录"**。

## 3. 经营概览（仪表盘）

登录后默认进入 **经营概览** 页面，展示四个核心数据卡片：

| 指标卡片 | 说明 |
|---------|------|
| **本月新增订单** | 当月新创建的订单总数 |
| **本月已开票金额** | 当月已开票订单的开票金额合计 |
| **本月实收金额** | 当月实际收款金额合计 |
| **待处理订单** | 当前状态为"待处理"的订单数量 |

下方区域包含：
- **近 7 日营收趋势图** — 折线图展示最近一周的订单金额变化
- **待处理订单列表** — 快速入口，点击可跳转到对应的订单详情

## 4. 客户管理

### 4.1 客户列表

左侧菜单点击 **"客户管理"** 进入列表页，展示所有客户信息。

列表字段：客户编号、客户名称、联系人、电话、结算方式、订单数、累计消费、未结清金额。

**操作：**
- **搜索：** 顶部搜索框输入客户名称关键字，按回车搜索
- **编辑：** 点击客户行右侧的 **"编辑"** 按钮
- **删除：** 点击客户行右侧的 **"删除"** 按钮
  - 有未完成订单的客户无法删除，系统会给出提示

### 4.2 新建/编辑客户

点击 **"新建客户"** 按钮，填写以下信息：

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 客户编号 | 否 | 自定义编号，不填则系统自动生成（格式：`CUST-YYYYDDMM-XXXX`） |
| 客户名称 | 是 | 不能与已有客户重名 |
| 联系人 | 否 | — |
| 联系电话 | 否 | — |
| 结算方式 | 否 | 如"月结 30 天""款到发货"等文本描述 |
| 备注 | 否 | 客户备注信息 |

**送货地址管理：**

在编辑客户时，可在对话框内管理送货地址：
1. 点击 **"送货地址"** 区域的 **"添加地址"** 按钮
2. 输入详细地址，点击 **"确认"** 添加
3. 可设置某个地址为 **"默认地址"**（新建订单时自动带出）
4. 支持编辑和删除已有地址

> 如果只添加了一个地址，系统自动将其设为默认地址。

## 5. 产品管理

### 5.1 产品列表

左侧菜单点击 **"产品管理"** 进入列表页。

列表字段：货物规格、单位、默认单价、状态、备注。

**操作：**
- **搜索：** 按名称或规格关键字搜索
- **编辑：** 点击产品行右侧的 **"编辑"** 按钮
- **启用/停用：** 点击右侧 **"启用"** / **"停用"** 开关
  - 停用的产品在新建订单时不可选择，已有订单不受影响
- **删除：** 点击产品行右侧的 **"删除"** 按钮
  - 被订单引用的产品无法删除，系统会提示

### 5.2 新建/编辑产品

点击 **"新建产品"** 按钮，填写以下信息：

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 货物规格 | 是 | 产品名称或规格描述 |
| 单位 | 否 | 如"个""箱""套""米"等 |
| 默认单价 | 是 | 新建订单时的默认价格，可在订单中修改 |
| 备注 | 否 | — |

> 订单中修改成交价不影响产品库中的默认单价。

## 6. 订单管理

### 6.1 订单列表

左侧菜单点击 **"订单管理"** 进入列表页。

**筛选与搜索：**
- **订单状态** — 下拉选择筛选（全部/待处理/生产中/已发货/已完成/已取消）
- **开票状态** — 下拉选择筛选
- **收款状态** — 下拉选择筛选
- **日期范围** — 按下单日期范围筛选
- **客户搜索** — 按客户名称搜索

**列表字段：**

| 列名 | 说明 |
|------|------|
| 客户单号 | 客户自定义的单号 |
| 下单日期 | 订单创建日期 |
| 订单交期 | 约定的交货日期 |
| 客户名称 | 关联客户 |
| 结算方式 | 从客户带出的结算方式 |
| 累计金额 | 订单内所有明细小计之和 |
| 送货地址 | 订单的送货地址 |
| 收款状态 | 带颜色标签展示 |
| 开票状态 | 带颜色标签展示 |
| 订单状态 | 带颜色标签展示，可下拉快速变更 |
| 已收金额 | 已收款金额 |
| 操作 | 查看/删除 |

**快捷操作：**
- **状态选择：** 直接在列表的"订单状态"列下拉选择，快速变更状态
- **收款操作：** 点击"部分收款"或"已结清"时，弹出对话框填写金额、方式、日期
- **查看：** 进入订单详情页
- **删除：** 仅"待处理"状态的订单可删除

### 6.2 新建订单

点击订单列表页的 **"新建订单"** 按钮，进入表单页。

**第一步：填写订单头信息**

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 客户名称 | 是 | 从下拉列表选择已有客户 |
| 客户单号 | 否 | 客户自定义的订单编号 |
| 下单日期 | 是 | 默认当天 |
| 订单交期 | 否 | 约定的交货日期 |
| 送货地址 | 否 | 自动带出客户的默认地址，也可手动输入 |
| 结算方式 | 否 | 自动带出客户的结算方式，可修改 |
| 备注 | 否 | — |

**第二步：添加订单明细（产品行）**

每行明细包含：

| 字段 | 说明 |
|------|------|
| 产品 | 从下拉列表选择（仅显示已启用的产品） |
| 规格 | 自动填充 |
| 客户产品编号 | 客户自定义的产品编号 |
| 单价 | 默认填充产品标准单价，**可修改** |
| 数量 | 输入大于 0 的整数 |
| 小计 | 自动计算（单价 × 数量） |

- 点击 **"添加行"** 增加新的产品行
- 点击行末的 **"删除"** 按钮移除该行
- 底部自动汇总显示 **订单总金额**

**第三步：开票与附件**

| 字段 | 说明 |
|------|------|
| 开票要求 | 选择：无需开票 / 需开 3% 增值税专用发票 / 需开普通发票 |
| 附件 | 支持上传 JPG、PNG、PDF 格式，单文件 ≤ 10MB |

**第四步：保存**

点击页面底部的 **"保存"** 按钮提交订单。保存成功后自动跳转到订单详情页。

### 6.3 订单详情与编辑

订单详情页展示完整的订单信息，分为以下区域：

**① 订单信息（可编辑）**

点击 **"编辑"** 按钮可修改以下字段：
- 客户单号
- 下单日期
- 订单交期
- 送货地址（从客户地址下拉选择，或手动输入）
- 结算方式
- 备注

**② 产品明细**

只读展示所有产品行信息：产品名称、规格、单价、数量、小计。

**③ 开票信息**

- 展示开票要求和开票状态
- 在详情页可修改发票号和上传发票附件

**④ 收款信息**

展示收款状态、已收金额、收款方式、收款日期。

**⑤ 发货信息**

展示每批发货记录：发货日期、产品明细、送货数量。

**⑥ 附件列表**

展示所有已上传的附件，支持：
- **预览** — 图片和 PDF 可直接在线查看
- **下载** — 保存到本地
- **删除** — 移除不需要的附件

**⑦ 操作日志**

以时间线形式展示所有状态变更记录：操作时间、操作类型、旧状态 → 新状态。

### 6.4 状态变更操作

在订单详情页右上方的"状态操作"区域，可进行以下操作：

**订单状态按钮：**
- **开始生产** → 将状态从"待处理"变更为"生产中"
- **标记发货** → 从"生产中"变更为"已发货"
- **完成订单** → 从"已发货"变更为"已完成"
  - 若收款为"未收款"，系统会弹出确认提示
- **取消订单** → 任意状态可取消
  - 已开票的订单无法取消
  - 取消后自动将开票状态设为"无需开票"

**开票操作：**
- 点击 **"开票"** 弹出对话框，选择开票类型（增值税专用发票 / 普通发票）
- 填写发票号，上传发票附件

**收款操作：**
- 点击 **"部分收款"** → 填写金额、方式、日期
- 点击 **"已结清"** → 填写金额 ≥ 订单总额

> **状态关联规则备忘：**
> - 已开票订单不能取消
> - 未取消的订单不能设为"无需开票"
> - 已结清时收款金额必须 ≥ 订单总额
> - 已有收款记录的不能退回"未收款"

### 6.5 发货管理

在订单详情页点击 **"发货"** 按钮，弹出发货对话框：

1. 展示该订单所有产品行的信息
2. 每行可编辑 **"送货数量"**（不能超过订单数量）
3. 填写发货日期
4. 点击 **"确认发货"** 保存

发货后，在"发货信息"区域可查看每批发货的明细记录。

## 7. 报表中心

左侧菜单点击 **"报表中心"** 进入，包含 4 个标签页：

### 7.1 按产品汇总（销量排行）

- 柱状图展示各产品的销售数量和销售金额
- 仅统计非"已取消"的订单
- 可按时间段筛选
- 点击 **"导出 CSV"** 下载数据

### 7.2 按客户汇总（客户对账单）

- 表格展示每个客户的：订单数、累计消费、已收款、未结清金额
- 可按客户筛选
- 点击 **"导出 CSV"** 下载数据
- 点击 **"导出 PDF"** 生成对账单 PDF（含客户信息和订单明细，订单编号显示为客户单号）

### 7.3 按时间段汇总（营收趋势）

- 柱状图 + 折线图组合展示
- 指标：新增订单数、已开票金额、实收金额
- 可按日/周/月聚合
- 自定义起止时间

### 7.4 按状态汇总

- 饼图展示各状态（订单/开票/收款）的订单数量分布
- 下方配套表格展示详细数据

## 8. 常见问题

### Q1: 为什么我无法删除某个客户？

该客户名下有**未完成**的订单（非"已完成"或"已取消"状态）。需要先完成或取消该客户的所有订单，才能删除客户。

### Q2: 为什么我无法删除某个产品？

该产品被已有订单引用。由于订单明细中保留了产品快照，出于数据完整性考虑，已引用的产品不可删除。

### Q3: 为什么订单无法取消？

请检查该订单的**开票状态**。如果已经开票（已开增值税专用发票或已开普通发票），则无法取消。如需取消，需先将开票状态回退为"未开票"。

### Q4: 为什么无法选择某个产品？

该产品可能已被**停用**。产品管理中可以启用/停用产品，停用后新建订单时不可选。如需使用，到产品管理中重新启用即可。

### Q5: 为什么"无需开票"选项不可用？

"无需开票"只能在订单**取消时自动设置**。如果订单处于其他状态，无法手动将开票要求设为"无需开票"。

### Q6: 收款时提示"金额不正确"？

- **部分收款：** 已收金额必须 **大于 0** 且 **小于订单总金额**
- **已结清：** 已收金额必须 **≥ 订单总金额**

### Q7: 上传文件失败？

- 检查文件格式是否为 JPG、PNG 或 PDF
- 检查文件大小是否 ≤ 10MB
- 如仍有问题，联系系统管理员

### Q8: 报表数据为什么和订单不一致？

请检查筛选条件是否正确：
- 报表默认统计所有订单，可使用时间段筛选
- 已取消的订单在"按产品汇总"中不纳入统计
- 如仍有疑问，可导出 CSV 数据与订单列表逐一核对
